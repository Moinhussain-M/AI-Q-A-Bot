            AI Q&A Bot

A simple AI-powered chatbot built with Python and Google Gemini.

Features
    Ask AI questions from the terminal
    Input validation
    Exit command support
    Environment variable configuration
    Error handling
    Gemini AI integration
Technologies Used
    Python
    Google Gemini API
    python-dotenv
Project Structure
    AI-QA-BOT
        app.py
        .env
        .gitignore
        requirements.txt
        README.md
Setup
    Clone the repository
    Create a virtual environment
    Install dependencies
pip install -r requirements.txt

Create a .env file

    GEMINI_API_KEY=your_api_key_here
    
Run the application
    python app.py
